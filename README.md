# Bankr Smart Wallet Tracker

Smart wallet tracking system for Base Chain and Robinhood Chain with Telegram DM alert notifications.

## Target Chains
- **Base Chain** (e.g. sample token `$BASECAT`: `0xb2000000000000000000004c27f6523082f41d01`)
- **Robinhood Chain**

## Features
- Smart wallet discovery (early buyers, DEX traders, KOL wallets, high win-rate addresses)
- Real-time buy alerts routed directly to Telegram DM
- Watchlist management & risk scoring
